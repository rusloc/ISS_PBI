- **Name and country/region come from two different table families.** Port *name* resolves through `analytical__air_sea_ports_codes.code`; *country* and *region* resolve through `portal.ports.port` / `portal.airports.airport`. Nothing in either query validates that the two keyspaces agree, so a code can resolve to a name and not to a country, or the reverse, with no signal. #idea
- **`public.analytical__iss_country_mapping_codes` is not a port table** but sits inside the same attribute block in all three files and is easily mistaken for one — key `iso_2_char_code` → `country_name`, it resolves `_destination_country_dest`. `analytical__regions` (`"Region Name"`, used by `OPERATIONS GEO RLS.sql` / `__GEO RLS GLOBAL.sql`) is organisational geography, unrelated to ports. #decision
- **COMS resolves ports without a single `join`.** Every port attribute in both COMS views is a scalar correlated subquery inside `pre_calc` (EK 67-261, PO 415-609), and every one of them aliases its source `ports` — including `portal.airports ports` and the sea+air `union all` derived table. Origin and destination are independent subqueries, not a POL/POD alias pair. Where the mode is unknown the query reads `select *, 'sea' from portal.ports union all select *, 'air' from portal.airports` and then references `ports.port` — column names come from the first branch positionally, so for airport rows `ports.port` is really `airports.airport`. Depends on both tables having identical column order and arity. #idea
- **AVS uses real joins, and joins `analytical__air_sea_ports_codes` three times.** `TRACKER CLIENT PROD MAIN.sql:189-196` — `o` (origin, `upper(trim(origin_port)) = o.code`), `d` (destination), `pa` (port of discharge, `pa.code = t.port_of_discharge_name`), plus `analytical__sea_ports_regions ps` on `ps.port_code = t.port_of_discharge_name`. Sibling files `TRACKER MAIN APP.sql` and `TRACKER CLIENT DEMO MAIN.sql` carry the same joins but feed no report in this repo (demo lacks the discharge block entirely). `TRACKER CLIENT PROD SKU.sql` / `… CONTAINER.sql` pass port codes straight through with no lookup. #decision
